# Start here: your first avionics contribution

**Goal:** join Avionics, build the sensor experiment, and prepare a small reviewed contribution. No hardware is needed to start.

| Contact | Ask about |
| --- | --- |
| **Tymon Cui ([@ccTymon](https://github.com/ccTymon))** | Joining the avionics work, choosing a task, firmware review, and hardware sessions. |
| **Kai ([@KaiYT1](https://github.com/KaiYT1))** | GitHub invitations, team access, Git setup, signing, permissions, and PR workflow problems. |

## 1. Join the team

Use the club's [joining page](https://utstar.sa.utoronto.ca/join-us.html) to find the student community. Coordinate avionics work with Tymon and give Kai your GitHub username for access. Accept the organization invitation and confirm you have joined the **Avionics** team.

Organization membership alone gives Read access; Avionics membership supplies Write access to this repository. You can read and clone the public repository while waiting. Members use branches in this repository; a personal fork is not required.

## 2. Follow the setup walkthrough once

Use the **[README terminal setup checklist](../README.md#terminal-setup-checklist)** as the single detailed walkthrough for installing tools, cloning, checking identity, signing, and building. It gives small command blocks, expected results, and recovery steps. Do not repeat the walkthrough if you already completed it.

At the signing step, use [the guided signing session with Kai](signing.md) if you need a new setup. You can continue reading code and building while arranging that session; finish signing before making your first contribution commit.

## 3. Choose and submit a first task

Agree on a small task with Tymon, then follow [CONTRIBUTING.md](../CONTRIBUTING.md). Request review from **UofT-STAR/avionics**. The branch rules require an Avionics-team approval and approval of the latest reviewable push by someone other than its pusher; a review from an unrelated reviewer alone is not enough.

## Ready for your next session

- [ ] Accepted the organization invitation and joined Avionics.
- [ ] Finished the README setup checklist and built the sensor experiment.
- [ ] Understand that `test1.cpp` builds while `main.cpp` is excluded.
- [ ] Published a feature branch with a signed commit marked Verified on GitHub.
- [ ] Opened a PR with test evidence and requested an Avionics-team review.

For troubleshooting, see [development.md](development.md). Arrange the [first hardware session](../README.md#first-hardware-session) separately with a teammate; completing software setup does not establish hardware or flight readiness.
